# 六種缺口生成器（G1–G6）

第 2 步開跑前讀這一份。共同規則在 SKILL.md〈第 2 步〉：每個生成器至少 2 個候選、不適用就寫明理由、生成當下就編號 `C01…`、只差一個變項取值的雛形要在**編號之前**併成一個帶參數的候選（編號給出去之後就不再合併，第二／三／四節一個編號一列）、每個候選寫成可檢驗的陳述。

下面每一節的〈舉證〉是**下判定前**要跑完的事；〈失效〉是這個生成器最常見的假陽性；〈落點〉是舉證沒跑完時，這個候選該進報告的哪一節。

## G1 負空間

**問**：哪些族群、情境、時期、地區、極端值從來沒被研究？把第 1 步找到的「研究對象／分析單位」預設反過來看——樣本都是大學生，那非學生呢？都是常態範圍，那極端值呢？

**舉證**：負空間候選在第 3 步一定要跑「上位概念」那一種查詢，否則很容易把「用別的詞寫過」誤判成 OPEN。題目在地界定時（台灣／華語圈／特定產業法規），中文索引那一輪是必要條件，不是加分項。

**失效**：空白不等於缺口。有些格子空著是因為該族群樣本取得不合倫理、或該情境根本沒有理論預期差異——這種要在〈最可能失敗的原因〉寫出來，不要假裝是機會。

**落點**：查詢詞問題沒解決 → UNSEARCHABLE（第三節）。

## G2 跨域移植

**問**：哪些學科解決過**結構上同型**的問題？刻意挑引用網路完全不重疊的領域（生態學的族群模型 → 組織離職；地震學的前兆訊號 → 金融危機）。模型讀過的領域比任何一個人都廣，這是它罕見的優勢。

**舉證（三段式，缺一不可）**——移植候選在定義上搜不到自己，所以搜法要換：

1. **搜目標領域的現象本身**，不搜你要移植的方法。目標領域的人如果早就在研究這個現象，用的是自己的術語（不要搜 `metapopulation + technician`，要搜 `turnover contagion`／`labor mobility network`）。
2. **搜來源領域方法的既有外銷紀錄**：`<方法名> applied to`、`borrowing from ecology`、`<方法名> in management`。同一個方法被搬過幾十次是常態，你多半不是第一個。
3. **檢驗結構同型是否可操作化**：說得出兩邊的哪個量對應哪個量、以及這個對應可以怎麼被否證。說不出來就只是比喻，不是研究設計。

**失效**：比喻冒充同型。第 3 項是唯一能擋住它的關卡，不要跳過。

**落點**：三項只要有一項沒跑，一律標〔待驗證〕進第三節，**不得判為 OPEN 或 ADJACENT，也不得列入存活候選**；第三節的〈補齊的具體動作〉就寫還缺哪一段、要跑哪個查詢。

## G3 預設反轉

**問**：把第 1 步找到的每一個**已量化**預設反過來，寫出最強的反面論證。只保留**可被實證檢驗**的反轉；純哲學爭辯留不下來。

**舉證**：輸入資格是硬的——**只有帶完整 `N／M′／M／K′／K` 的預設可以當 G3 的輸入**（格式見 SKILL.md 第 1 步）。標〔印象，未驗證〕的預設（含 M′ < 3 者）不得長出候選，因為整條產線的第一顆扣子就會扣錯，後面所有搜尋證據都只是在替一個沒查證的前提背書。**承接自地形報告的預設同一條處理**：〔承接自地形 W…〕在補跑取樣框之前效力等同〔印象，未驗證〕，**不得當 G3 輸入**——地形模式的舉證標準是代表性錨定文獻，本來就低一階，它的用途是告訴你哪一條值得補框，不是替你省掉補框。要反轉它就先對**那一條**補跑取樣框，補完標成〔承接自地形 W…，已補取樣框〕再進 G3。**每個 G3 候選的〈缺口類型〉欄要逐字寫成「G3 預設反轉（反轉 A1）」**，括號裡指名反轉的是第一節哪一條預設——不指名，上面這條輸入資格就沒辦法被查核。

**失效**：把「我沒看到有人檢驗過」寫成「沒有人檢驗過」。第 1 步的推翻性檢索（K′／K）就是為了把這句話換成有界的陳述。

**落點**：預設未量化 → 這個候選根本不該被生成；已生成的要退回並在報告寫明退回理由。**降級階梯落在階 2／3 時（沒有 `brief`／`pick`），取樣框在定義上組不出來，第一節全部是〔印象，未驗證〕，G3 一律寫「不適用（無摘要層抽樣工具）」**——不要為了讓 G3 看起來成立而編造 `pick` 索引（見 [elimination-engine.md](elimination-engine.md)〈四、降級階梯〉）。

## G4 矛盾獵捕

**問**：效果量互相打架、重現失敗、或不同 meta-analysis 結論相反的地方在哪裡？查詢詞沿用 lit-review 的反面證據組：`no association`／`null effect`／`mixed evidence`／`no significant`／`contrary` × `meta-analysis`／`longitudinal`／`replication`。

**舉證**：這一層**可以**在摘要層做——meta-analysis 與 systematic review 的摘要通常會報 pooled effect size 與信賴區間，replication 研究的摘要也會直說重現成功與否。但「研究 A 與研究 B 效果量相反」這種宣稱，必須把**兩個數字連同各自出處逐字引出來**，並註明有沒有檢查信賴區間是否重疊（沒檢查就寫沒檢查）。

**失效**：把「兩個數字不一樣」當成矛盾。若無法解釋兩者為何不一致（調節變項、納入條件、分析選擇），這只是一個觀察，不是一個研究問題。

**落點**：說不出機制 → 標〔矛盾已觀察，機制未知〕進第三節；〈補齊的具體動作〉寫要比對哪兩篇的哪個條件。

## G5 構念效度落差

**問**：文獻宣稱在測 X，實際上測的是 Y？

**舉證**：**需要全文，摘要層無法成立。** 量表題項與測量段落只存在於全文，摘要永遠不會有題目文字；沒讀到題項或測量段落就宣稱「它其實測的是 Y」，是憑印象攻擊整批文獻的基礎。流程：`lit_api.py fulltext <DOI>` 拿位置 → **用 WebFetch／PDF 讀取工具／EndNote `read_pdf_section` 真的把「方法—測量」段落讀出來** → 逐字引出題項文字或量表名稱 → 才可以下構念質疑。`fulltext` 回的是連結不是內文，沒有這個讀取步驟，G5 永遠停在原地。

**失效**：拿量表**名稱**當證據。名稱相同的量表常有多個版本與刪題版，要引的是題項或測量段落的原文。

**落點**：拿不到全文（付費牆、無 OA）→ 標〔待全文查證〕進第三節，**不得進入存活候選、不得給新穎性判定**；〈補齊的具體動作〉寫「經機構訂閱或館際合作取得 <DOI> 全文，讀方法段」。取得了全文但只讀到摘要級資訊，也一樣進第三節。**降級階梯落在階 2／3 時沒有 `fulltext` 這一步：若能自行找到 OA PDF 並真的讀到「方法—測量」段落，G5 仍可照常進行；找不到就寫「不適用（無全文取得途徑）」**，不得用摘要或印象補（見 [elimination-engine.md](elimination-engine.md)〈四、降級階梯〉）。

## G6 未被訓練過的資料

**問**：從第 0 步第 3 項出發——使用者手上這批資料，能回答什麼別人回答不了的問題？這是整個技能最大的槓桿，因為模型沒見過的輸入必然產生新的分析結果。

**舉證**：資料獨有性不能只憑使用者一句話，第 3 步照樣要跑「有沒有人用類似資料做過同一件事」的查詢（同資料型態不同來源、公開資料集的同型分析）。可行性欄要寫清楚資料的**取得授權狀態**（已有／申請中／尚未接觸）與保密層級——拿不到授權的資料等於沒有資料。

**失效**：把「資料是我的」誤當成「問題是新的」。同一個問題別人用別的資料早就回答過，仍然是 DONE 或 CROWDED。

**落點**：使用者未提供資料條件（第 0 步第 3 項缺答）→ **整個 G6 標為〈未執行：使用者未提供資料條件〉**，寫進表頭〈降級聲明〉，不得靜默略過；補答之後值得重跑。
